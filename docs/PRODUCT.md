# DiscordX

<!-- impeccable:product-schema 1 -->

## Platform

android

## Product purpose

DiscordX gives Discord Phoenix users an in-client place to discover and toggle optional local plugins. The first supported target is the supplied Android alpha on the Googlebook VMware guest.

## Operating context

The user asked for the plugin-management workflow familiar from Equicord and Vencord. DiscordX provides its own Android Plugins panel and supports both touch and keyboard. Plugins ship with DiscordX and store their settings on the device.
